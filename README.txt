Estructura:
- index.html
- styles.css
- app.js
- manifest.json
- service-worker.js
- data/monsters.json
- assets/

La biblioteca de monstruos se genero durante el desarrollo desde Gloomhaven Monster Stats.xlsx.
La app no necesita leer el Excel durante el uso normal.

Sube la carpeta completa a GitHub Pages o a cualquier servidor estatico.
En Chrome Android, abre la URL y usa "Añadir a pantalla de inicio" para instalar la PWA.
